# CampusRide mobile prototype

Expo / React Native app for iOS and Android. Run `npm install` then `npx expo start`; open with Expo Go or build native binaries using Expo's build service. Requires Node.js and an iOS simulator, Android emulator, or physical device.

Prototype only: state lives on one device. Email checks only the .edu format. There is no actual identity verification, secure license upload, backend, real matching, payment, seat reservation, real-time chat, live location, or secure one-time pickup-code validation. Do not upload driver licenses or use this for real trips. Driver acceptance and booking are simulations. The offer-ride price field uses a placeholder suggestion; real route-based pricing and address geocoding are not connected. Add server-side authentication, verification, payments, mapping, safety, and secure storage before real use.
